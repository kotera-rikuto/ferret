# design/

デザイン検証用のモック置き場。実装（`app/` / `components/`）からは参照しない。

## ファイル

- `stages-mock.html` — ステージ選択画面のモック（モバイル幅・ライト）。単体でブラウザで開ける（`open design/stages-mock.html`）。
  マスコット画像だけ `../public/character_nobg.png` を相対参照している。
- `stages-desktop-light.html` — デスクトップ版（ライト）。Duolingo Web と同じ3カラム構成:
  左ナビ / 中央パス（章バナー sticky）/ 右ウィジェット（Free の1日3問・進捗・Pro 案内）。
- `stages-desktop-dark.html` — デスクトップ版（ダーク・引き締めパターン）。レイアウトとJSはライト版と同一で、
  差分は `:root` のカラートークンと影・グローのみ。黒は zinc ではなく暖色系の黒（エスプレッソ）。
  アンバーは面で塗らず「光」として使う（クリア済みノードのグロー、現在地の発光、未解放は光らせない）。
- `title-desktop-light.html` — タイトル画面。マスコットを主役サイズに。primary は「はじめる」（新規獲得優先）
- `login-desktop-light.html` — ログイン画面。OAuth（準備中チップ付き）→ または → メール+パスワード。
  新規登録画面は同じカードでフィールド構成だけ変える想定
- `problem-desktop-light.html` — 問題画面。左上×（中断）/ コードパネルだけ常にダーク / 下部固定フッターに
  OpenAI 送信注記（仕様書 §9.5）+ 回答ボタン（10字未満は disabled）/ 採点待ちはフェレットのローディング演出
- `result-desktop-light.html` — リザルト画面。統計チップ3枚（巨大スコア1つをやめる = 0点が罰に見えない）/
  XPバー / フィードバックは v3 の praise・next_focus の2枠 / 主ボタン1本、もう一度・ふりかえりはテキストリンク
- `problem-samples-desktop-light.html` — **読解型6種の具体的な問題**を問題画面レイアウトに流し込んだもの。
  上部のグレー帯（モック専用UI）で トレース/意図/ズレ/影響/命名/仕様 を切替。
  ステージ対応は問題作成ガイドの6問検証に合わせた（1/15/5/59/53/78）。レイアウト上の新要素:
  - 影響型: コード + 実行ログの**2パネル**（ログヘッダに ERROR 表示）
  - 命名型: 関数の中身を `/* …… */` で伏せる表現
  - 仕様型: テストファイル名をパネルヘッダに表示（maskEmail.test.js / Vitest）
  - ズレ型: 意図コメントを含むコード
  - トレース型のコードは問題作成ガイドの記入例（applyCoupon）をそのまま使用。他5問は実務由来ルールで自作した
    **下書きなので、実際のコンテンツ作成時の叩き台にできる**

### クリックで通しになっている（簡易プロトタイプ）

```
title → login → （ログイン）→ stages → （挑む）→ problem → （回答する・採点演出2.4秒）→ result
                                  ↑______________________________________________________|
                                     「次のステージへ」「もう一度挑む」で往復できる
```

## stages-mock.html で検証している方向性

| 現状の実装 | モックでの置き換え | 元ネタのパターン |
|---|---|---|
| 全画面ダーク（zinc-950）+ amber | 暖色クリーム背景 + アンバー（コードだけダークの方針は維持） | Duolingo / Progate 系の明色ベース |
| 中央モーダル + ボタン2つ | ノードにアンカーしたポップオーバー + 主ボタン1本（外側タップで閉じる） | Duolingo のノード吹き出し |
| むき出しのログアウトボタン | 右上ギアに格納 | 学習アプリ全般 |
| 絵文字アイコン（✅🔒🐾） | SVG アイコン | — |
| フラット rounded-full ボタン | 下辺が濃い「押し込み」ボタン（active で沈む） | Duolingo の 3D ボタン |
| 章見出しなし | 章バナー（sticky・スクロールで現在の章に追従）+ 章の区切り帯 | Duolingo のユニットヘッダー |
| — | 起動時に現在地へ自動スクロール、離れたら「現在地へ」FAB | Duolingo の jump-back |
| — | 現在地ノード: 拡大 + パルス輪 + スタート吹き出し + マスコット隣接 | Candy Crush / Duolingo |

## カラートークン（マスコットのクリーム×こげ茶から起こした）

Tailwind に移すときの対応目安:

| トークン | 値 | 用途 | Tailwind 近似 |
|---|---|---|---|
| `--bg` | `#fdf8ec` | アプリ背景 | `amber-50` 寄りのカスタム |
| `--bg-deep` | `#f1e8d2` | ページ余白 | カスタム |
| `--line` | `#ece0c6` | 枠線 | カスタム |
| `--ink` | `#4a3b28` | 本文テキスト | `stone-800` 寄り |
| `--muted` | `#a3937a` | 補助テキスト | `stone-400` 寄り |
| `--brand` | `#f59e0b` | 主ボタン・現在地 | `amber-500` |
| `--brand-deep` | `#c47000` | ボタン下辺（押し込み） | `amber-700` |
| `--brand-soft` | `#fbbf24` | クリア済みノード | `amber-400` |
| `--locked` | `#e9e0cb` | 未解放ノード | カスタム |

フォントは M PLUS Rounded 1c（丸ゴシック）。実装時は `next/font/google` で読み込む。
