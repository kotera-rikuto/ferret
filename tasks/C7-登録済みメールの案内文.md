## 何をするか

**新規登録のあとに出る「確認メールを送りました」の画面に、一文足す。**

足す文（案。表現は変えてよい）

> すでにご登録のメールアドレスの場合、メールは届きません。ログイン画面からお進みください。

---

## なぜ必要か

**いま、登録済みのメールアドレスでもう一度「新規登録」すると、
画面は「確認メールを送りました」と言うのに、メールは届かない。**

Supabase が「そのアドレスは登録済みです」と教えない作りになっているため
（登録済みかどうかを外から調べられないようにする、よくある作り）。
**これはこちらでは止められない。** メール確認を必須にしている限り、この動きになる。

結果として、**前に登録したことを忘れた人が、来ないメールを待ち続ける。**
新規登録は利用者が最初に触る画面なので、ここで詰まるとそのまま離れてしまう。

一文足すだけなら、**全員に同じ文面が出る**ので「登録済みかどうかを教えない」という
性質は崩れない。教えるのは「もし登録済みならこうしてください」という案内だけ。

---

## 手順

1. `app/register/page.tsx` の `sent === true` の分岐（「確認メールを送りました」の画面）に一文足す
2. すでにある「ログイン画面へ」のリンクの**すぐ上**に置く。案内と行き先が離れていると効かない
3. 本文の文字色は既存の `text-muted` に合わせ、**主役（確認メールの案内）より弱く**する
4. `npm test` と `npm run build` を通す

### テストについて

`tests/e2e/auth.spec.ts` の **E-112** が、この画面の現状を固定している。
文面を足すだけならこのテストは通ったままのはず（「登録済みです」という文言は出さないため）。
**落ちた場合は、足した文が「登録済み」と断定する書き方になっていないか確かめること。**
