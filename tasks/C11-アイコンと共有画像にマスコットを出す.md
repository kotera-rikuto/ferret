## なぜ必要か

**同じ「ferret」で競合が先にいる。**

検索結果で並んだとき、**片方はロゴ、片方は地球のマーク**という状態です。
地球のマークは「設定されていないサイト」の見た目なので、**個人が作った実験的なものに見えます。**

そして共有されたときも同じです。いま Slack や X にリンクを貼っても、
**絵の無い素っ気ないリンク**になります。M1（技術記事からの集客）で記事に
リンクを貼る予定なので、**そこで最初に目に入るのがこの絵**になります。

## 手順

1. 上の5点を決める
2. **アイコンを作る**
   - マスコットから顔を切り出し、背景を付け、正方形にする
   - `app/icon.png` に置く（**Next.js が自動でタブと検索のアイコンにする。設定は不要**）
   - **ファイルサイズを数十KBに落とす**
3. **`app/apple-icon.png`** を置く（スマホでホーム画面に追加したときの絵。180×180）
4. **共有カードを作る**
   - `app/opengraph-image.tsx`（案A）または画像ファイル（案B）
   - 1200×630
   - **`metadata.openGraph` に画像の指定を足す**（`app/layout.tsx`。いま画像だけ抜けている）
5. **確認する**
   - タブにマスコットが出る
   - **リンクを Slack や X に貼ってカードを見る**
     （⚠️ **キャッシュされるので、直しても古い絵が出続けることがある**。各サービスの
     デバッグツールで再取得させるか、時間を置く）
   - 検索結果への反映は**索引の更新待ち**なので、すぐには変わらない
6. `npm run build`

### 途中で分かったこと（この作業の中身）

- **`app/opengraph-image.tsx` を置くだけでは、ほとんどのページに og:image が付かない。**
  Next.js は og:image を足してくれるが、**`openGraph` を書いたページではその `openGraph` ごと
  差し替わり、足してもらった画像も消える。** 実測では何も書いていない `/login` `/register` には付き、
  `publicPageMetadata` を通す `/terms` `/privacy` `/changelog` には**付かなかった**
  （`/` だけは絵と同じ階層なので別経路で付いていた）。
  → `OPEN_GRAPH_BASE` と `TWITTER_BASE` にURLを持たせて解決。歯止めは **U-846**。
- **X は `twitter:card` を書かないと絵を小さな四角に縮める**（既定が `summary`）。
  1200×630 を用意しても意味が無くなるので `summary_large_image` を宣言した。
- **画面のフォント（`next/font/google`）は画像には効かない。** `next/og` はフォントの
  バイト列を渡さないと日本語を1文字も描けない（全部豆腐）。切り出した実体を置いてある。
- **虫眼鏡は顔から外せない**（レンズが左頬に重なっていて、外すと描かれていない部分が穴になる）。
  レンズの右端が頭の輪郭とほぼ同じ位置だったので、**切る位置をそこに置いて画面から外した。**
- **しっぽを矩形で落とすと切り跡が残る。** 頬の輪郭を垂直に切った線が 256px でも見えたので、
  頬としっぽの**隙間を通る斜めの線**で落とした（`TAIL_CUT`）。
- **見出しの字の大きさは「いちばん長い節が1行に収まるか」で決まる。** 62px では
  「読め / る、」の位置で折れたので 52px にした（全角11文字 ≒ 11em、列の内寸 604px）。
