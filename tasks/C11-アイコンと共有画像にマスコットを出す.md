## 何をするか

**検索結果とリンク共有のときに出る絵を、既定のものからマスコットに変える。**

### いまの状態（2026-08-26 実測・オーナーのスクリーンショットで確認）

Google で検索すると、こう出ている。

```
[FO]  ferret One          ← 他社。ロゴが丸の中に出ている
      https://ferret-one.com

[🌐]  ferretcode.com      ← こちら。既定の地球アイコン
      https://ferretcode.com
      Ferret（フェレット）| コードリーディング特化の ...
      他人のコードが読める、AI時代のエンジニアに。…
```

**タイトルと説明文は C8 で整っている。** 足りないのは**絵だけ**。

## なぜ必要か

**同じ「ferret」で競合が先にいる。**

検索結果で並んだとき、**片方はロゴ、片方は地球のマーク**という状態です。
地球のマークは「設定されていないサイト」の見た目なので、**個人が作った実験的なものに見えます。**

そして共有されたときも同じです。いま Slack や X にリンクを貼っても、
**絵の無い素っ気ないリンク**になります。M1（技術記事からの集客）で記事に
リンクを貼る予定なので、**そこで最初に目に入るのがこの絵**になります。

---

## ⚠️ オーナーに確認すること

> **① アイコン（丸の中の絵）に何を出しますか**
> - **案A: マスコットの顔だけ**（おすすめ）
>   **検索結果の丸は16〜32px**しかありません。全身だと何か分かりません
> - 案B: ロゴ（Ferret の文字）— 他社（ferret One）は文字ロゴです
> - 案C: 顔 + 文字
>
> **② 背景をどうしますか**
> `character_nobg.png` は**背景が透明**です。透明のまま使うと
> **暗いテーマのブラウザで見えなくなります。**
> - **案A: ブランドカラーの丸い背景を敷く**（おすすめ）— 明暗どちらでも見えます
> - 案B: 白背景
>
> **③ 共有カード（大きい絵）に文字を入れますか**
> こちらは 1200×630 で大きく出ます。
> - **案A: マスコット + コアコピー**（おすすめ）
>   「他人のコードが読める、AI時代のエンジニアに。」が仕様書で確定しています
> - 案B: マスコットだけ
>
> **④ 共有カードの作り方**
> - **案A: コードで生成する**（`opengraph-image.tsx`。文言を直すのが楽）
> - 案B: 画像ファイルを作って置く（自由度は高いが、直すたびに作り直し）
>
> **⑤ 素材の重さについて**
> いまのマスコット画像は **1.3〜1.6MB** あります（`character_nobg.png` は 1.6MB）。
> **アイコンは数十KBに縮める必要があります。** 縮小して切り出す作業が要ります。

---

## 手順

1. 上の5点を決める
2. **アイコンを作る**
   - マスコットから顔を切り出し、背景を付け、正方形にする
   - `app/icon.png` に置く（**Next.js が自動でタブと検索のアイコンにする。設定は不要**）
   - **ファイルサイズを数十KBに落とす**
3. **`app/apple-icon.png`** を置く（スマホでホーム画面に追加したときの絵。180×180）
4. **共有カードを作る**
   - `app/opengraph-image.tsx`（案A）または画像ファイル（案B）
   - 1200×630
   - **`metadata.openGraph` に画像の指定を足す**（`app/layout.tsx`。いま画像だけ抜けている）
5. **確認する**
   - タブにマスコットが出る
   - **リンクを Slack や X に貼ってカードを見る**
     （⚠️ **キャッシュされるので、直しても古い絵が出続けることがある**。各サービスの
     デバッグツールで再取得させるか、時間を置く）
   - 検索結果への反映は**索引の更新待ち**なので、すぐには変わらない
6. `npm run build`

## 注意

- **元のマスコット画像を消さないこと。** 加工したものは別名で置く
- **共有カードに問題の中身を写さないこと**（答えが見えてしまう）
- **M2（LP）の見出しと文言を揃えること。** カードのコピーと LP の見出しが違うと、
  クリックした人が別のサービスに来たように感じます
- **検索結果の反映は遅い。** 索引が更新されるまで既定のアイコンのままです。
  「直したのに変わらない」は正常なので、**焦って作り直さないこと**
- 共有カードの見え方は**サービスごとに違う**（切り取られる範囲が変わる）。
  端に大事なものを置かないこと
