## UI基本方針

- コードは常にダークテーマ、Shiki でシンタックスハイライト
- フェレットマスコットはローディング・リザルト・昇格時に登場
- ポジティブ表示のみ（「間違い」「失敗」は使わない）

### 3. ステージ選択画面

ソシャゲのマップ風。下からスタートして上に登っていく。スクロールは下が最新（現在地付近）から始まり、上に向かって未来のステージが続く。

```
┌─────────────────────────────────────┐
│  🐾  Lv.4          🔥 7日    ⚙️    │
├─────────────────────────────────────┤
│                                     │
│        🔒8                          │  ↑ 上に行くほど先のステージ
│         ·  ╲                        │
│         ·   🔒7                     │
│                                     │
│ ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  │
│   STAGE 2  エラー処理               │
│ ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  │
│                                     │
│        🔒6                          │
│         ·  ╲                        │
│         ·   🔒5                     │
│                                     │
│ ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  │
│   STAGE 1  コードの基本             │
│ ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  │
│                                     │
│        🐾4   ← 現在地               │
│         ╱                           │
│        ✅3                          │
│         ╲                           │
│          ✅2                        │
│         ╱                           │
│        ✅1                          │
│                                     │
└─────────────────────────────────────┘
```

- 起動時は現在地（🐾）が画面中央に来るようにスクロール位置を合わせる
- **✅** クリア済み（色付き）
- **🐾** 現在地（フェレットが立っている）
- **🔒** 未解放（グレーアウト）
- クリア済みの道は実線、未到達は点線

### 4. 問題画面

コードが上、テキストボックスが下。全問題共通のレイアウト。

```
┌─────────────────────────────────────┐
│  ← 戻る    STAGE 1 - 問題 4 / 4    │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────────────────────┐    │
│  │ async function getUser(id) { │   │
│  │   const res = await fetch(  │    │
│  │     `/api/users/${id}`      │    │
│  │   )                         │    │
│  │   return res.json()         │    │
│  │ }                           │    │
│  └─────────────────────────────┘    │
│                                     │
│  このコードは何をしていますか？      │
│                                     │
│  ┌─────────────────────────────┐    │
│  │                             │    │
│  │                             │    │
│  │                             │    │
│  └─────────────────────────────┘    │
│                                     │
│  ［ 回答する ］                      │
└─────────────────────────────────────┘
```

択一問題の場合はテキストボックスの代わりに選択肢を表示するだけ。

### 5. リザルト画面

シンプルにスコアと経験値のみ。解説は別画面に分離。

```
┌─────────────────────────────────────┐
│                                     │
│   ⏱  1:24          Score  +92pt    │
│                                     │
│   🐾  EXP + 120  ▓▓▓▓▓▓░░░  68%   │  ← フェレットを経験値バー横に
│                                     │
│                                     │
│        ［ 振り返る 📖 ］            │  ← 解説画面へ遷移
│                                     │
│   ［ 戻る ］     ［ 次のステージへ ］│  ← 横並び
│                                     │
└─────────────────────────────────────┘
```

### 5-1. 振り返り画面（リザルトから遷移）

```
┌─────────────────────────────────────┐
│  ← 戻る              振り返り       │
├─────────────────────────────────────┤
│                                     │
│  ──── あなたの回答 ────             │
│  「ユーザーをIDで検索する」          │
│                                     │
│  ──── 解説 ────                     │
│  このコードはIDを使ってユーザー      │
│  情報を取得しています。ただし        │
│  エラー時の処理がないため、          │
│  fetchが失敗した場合に              │
│  unhandled rejectionになります。    │
│                                     │
│  ──── 正解例 ────                   │
│  · fetchはPromiseを返すため、        │
│    失敗時にエラーが発生する          │
│  · try/catchまたは.catch()で        │
│    エラーを受け取る必要がある        │
│  · エラー処理がないと本番環境で      │
│    クラッシュする可能性がある        │
│                                     │
└─────────────────────────────────────┘
```

## 将来実装候補（MVP後）

- 穴探しゲーム: コードの行をタップしてバグ箇所を指摘するインタラクティブモード
- AI対戦モード: ユーザー vs Ferret AI で同じコードを採点して対決
- 段位・認定証: 一定レベル到達で認定証PDF発行
- 公開プロフィール: `ferret.io/u/[username]`
- ストリーク: 連続ログイン日数カウント
